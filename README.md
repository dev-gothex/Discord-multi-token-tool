# Discord Raid Tool

A multi-feature Discord tool designed for various automated actions such as token reactions, token leaver, raid features, nickname changing, and more.

> The author is **not responsible** for any misuse of this tool.

---

##  Features

- Token Reaction  
- Token Leaver  
- Raid Functions  
- Change Nickname  
- Multi-token Support  
- Easy-to-use Menu Interface  

> More features will be added in future updates.

---

##  Requirements

- Python 3.8 or higher  
- pip (Python package manager)

---

##  Installation

### Step 1: Install Dependencies

Open your Terminal (CMD or PowerShell) in the project directory and run:

```bash
pip install -r requirements.txt
```

##  Configuration
### Step 2: Add Tokens
- Open the file tokens.txt
- Paste your Discord tokens inside
- One token per line

Example:
```txt
token_1_here
token_2_here
token_3_here
```
##  How to Run
### Step 3: Launch the Tool
Run the main script with the following command:
```bash
python obf-xynt.py
```
